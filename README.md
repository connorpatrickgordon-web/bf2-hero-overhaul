# BF2 Hero Overhaul

A Star Wars Battlefront II mod that customizes hero names, bios, and UI text using Frosty Editor and Frosty Mod Manager.

## What this project does

- Renames heroes to custom titles (e.g., “Connor Ren” for Kylo).
- Updates hero bios with new backstories and flavor text.
- Adjusts UI strings to better match custom skins or themes.
- Provides a simple workflow for editing EBX localization data safely.

## How it works

This project uses:

- Frosty Editor to edit EBX files and localization strings.
- Frosty Mod Manager to load the resulting `.fbmod` files.
- A documented process for finding hero data, editing text fields, and exporting mods.

## Why it exists

Battlefront II has an active modding community, but clear guides for hero text/UI customization are limited.  
This project aims to:

- Make it easier for players to personalize their heroes.
- Share a repeatable workflow for safe text/UI modding.
- Serve as a base for more advanced cosmetic or gameplay mods.

## Planned improvements

- Step‑by‑step tutorials for new modders.
- Example `.fbmod` files for popular heroes.
- Scripts or tools to automate common text changes.
